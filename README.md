# Projeto5

# Descrição

Este projeto consiste em um sistema no qual o usuário tem de informar os comprimentos dos catetos e então, o sistema fará a conta por ele.

# Tecnologia Usada

Python 3.14.

# Como Rodar?

Coloque-o no PyCharm, clique no botão de run e então, informe os valores dos catetos, podendo ser qualquer número que você quiser.

# O que eu aprendi?

A usar bibliotecas ao lado de funções como float, int, print e variáveis.
